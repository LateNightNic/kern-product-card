# Kern product card
This is a fictional ecommerce product card for the fictional type foundry, KERN. It features 3 cards with different fonts. 

## About
It provides a preview of a font that a user may wish to trial or license. Users will see which category the font belongs to, it's status as a new product or bestseller and price. 

## Built with
- HTML
- CSS (Flexbox, CSS custom properties)

## What I learned
I now understand that justify-content controls the main axis and align-items controls the cross axis and that these swap when flex-direction changes.

I understand the difference between rem and the compound effect of em. The compounding em sizing is great for scalable button-text, in which the padding is should also scale with font-size. Rem is better for overall sizing (font-size, margins / padding etc). Px measurements are good for elements that shouldn't resize across screens (e.g. border radius)
